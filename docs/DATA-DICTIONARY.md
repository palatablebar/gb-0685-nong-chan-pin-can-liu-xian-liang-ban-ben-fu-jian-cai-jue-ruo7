# 检测区间与复检

采样日期选择限量标准[start,end)，不使用报告出具日。同产品同残留项目在采样日须恰有一条有效标准，方法须在适用范围内。浓度统一mg/kg：mg/kg、ppm折1，ug/kg、μg/kg、ppb、ng/g折0.001；单位写法先NFKC归一、忽略大小写与分隔符，`μg/kg`/`µg/kg`/`UG/KG`等视为同尺度。检出限LOD必须大于0。

定量值以[value,value]记录，低于LOD的定量值拒绝。ND或<LOD以[0,LOD)记录，<后的数值必须等于报告LOD。区间上界≤限量为PASS，下界>限量为FAIL，其余UNCERTAIN。<0.01相对0.005限量为不确定，不能当零。

复检relation指向原报告，必须同样本、同批次、同产品、同残留项目、同方法、同采样日，报告日严格更晚。引用环、悬空引用与异样本引用隔离。每样本/项目只允许一个原始报告根。有效复检按reported、version取最新；并列结果**按折算mg/kg后的区间**比较，区间一致即视为同一结论、可共同支撑，不因书写单位或小数位不同判为矛盾。并列区间矛盾时采信失败：矛盾复检以 SUPERSEDE（采信失败，保留原结论）隔离，原有已确认结论保留。其他残留项目不因复检被覆盖。批次按FAIL>UNCERTAIN>PASS取最高风险等级，等级沿用决定该等级的合并浓度区间。

## 跨单位支撑

同一产品的原检与复检可以用不同单位书写同一浓度（如原检 `0.004 mg/kg`、复检 `4 ug/kg`）。工作台在复检裁决页列出每份可共同支撑结论的报告、其原单位、折算后的共同mg/kg区间与说明。只有折算后区间完全一致的报告才共同支撑；区间不同但重叠不构成共同支撑，仍按最新有效复检单独判定。批次等级与归档资格沿用该合并区间：批次结论由携带该区间的项目决定，归档要求输入对账平衡且每个已采纳样本/项目组各有一条结论（采信保留旧结论时仍满足覆盖）。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

同一报告ID的多个版本先选最高version，再构建复检引用链；历史版本留作采信证据，不重复参与最终项目判定。封存证据包含原始报告（含被复检替代的初检）、计算结论、跨单位支撑说明与每条隔离记录的原因码及原值；同源重跑不新增记录，也不改换已记录（含已复核）的结论。
